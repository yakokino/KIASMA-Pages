# Top page images

Place the two supplied images in this folder using these exact filenames:

- `kiasma-logo.png` — the logo displayed at the top
- `home-visual.jpg` — the large image displayed in the center

Recommended image preparation:

- Use a transparent-background PNG for the logo.
- Use a landscape image close to a `1.955:1` aspect ratio for the main visual.
- If the main visual is provided as PNG or WebP instead, update its filename in `index.html`.
